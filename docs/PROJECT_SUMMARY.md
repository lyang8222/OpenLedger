# OpenLedger 项目封存总结

封存日期：2026-08-04 · 归档标签：v0.1.0

## 项目定位

本地优先的智能收支统计 App：一张支付截图，自动完成记账，快速掌握收支。

## 已完成功能

### 核心记账

- 一个主按钮导入支付截图（相册 PHPicker 免权限 / 拍照 / 系统分享）
- 本机 Vision OCR + 四平台模板解析（微信 / 支付宝 / 云闪付 / 抖音）
- 字段提取：金额、商户、时间、状态、交易单号（打码单号标记待补录）
- 确认页人工修正缺失字段
- 保存去重：交易单号哈希为主，金额+商户+时间兜底
- 保存动画：金额胶囊流入收支页 + 新记录高亮
- 手动记账兜底
- 截图后回前台导入询问

### 对账

- 支付宝 CSV（GB18030/UTF-8）、微信 xlsx（内置 ZIP/XML 解析）、官方加密 zip（ZipCrypto）
- 匹配引擎：已匹配 / 漏记 / 金额不一致 / 重复 / App 有而账单无
- 一键补记，漏记横幅提醒
- 真实账单验证：支付宝 535 笔、微信 171 笔，与平台声明一致

### 统计与分类

- 收支图表：条形 / 饼图 / 折线 / 曲线 / 分类占比，均可点按查看数字
- 自动分类（内置关键词）+ 用户自定义规则（自定义优先）
- 今日/本月支出小组件（App Group 共享）

### 隐私与安全

- Face ID / 触控 ID 应用锁 + 后台自动锁定遮罩
- 敏感字段 AES-256-GCM 加密，密钥 Keychain（仅本设备）
- 加密导出/恢复（口令派生密钥，友好错误提示）
- 通知默认隐藏金额；脱敏分享卡（交易单号打码）
- 无网络权限、无遥测、无相册权限

### 提醒

- 每日 / 每周 / 每月 / 每季度 / 每年收支总结（本地通知，前台也展示）
- 订阅检测与到期提醒（同商户 + 同金额 + 周期匹配）

## 验证状态
